# 胡了么 —— 多玩法可配置麻将计分微信小程序

> 面向不同地区麻将规则差异大的痛点，支持**多种地方玩法规则可配置**的麻将计分小程序。
> 独立开发（需求设计 + 前端 + 云函数后端 + 自动化测试）。

## 功能特性

- 🀄 **房间对战计分**：创建/加入房间，实时同步分数，支持房间二维码分享
- ⚙️ **规则可配置**：底分、自摸/点炮倍数、明/暗/补杠分、封顶番、买马数、庄家倍数等 12 种规则参数，房主可在配置面板自定义；支持黄梅麻将「算炮数」等地方特色
- 🧮 **自动结算**：结算引擎（scoreService）支持自摸、点炮、杠、流局、买马等完整场景，分数守恒（总和恒为 0）
- 🔄 **实时同步**：基于授权云函数分页快照与串行轮询同步；前台心跳判断在线，支持后台恢复
- 🕐 **自动关房**：定时任务归档无人房间并保留战绩，有前台心跳时不因长时间未记分而关房
- 🧪 **自动化测试**：Jest 单元测试 + fast-check 属性测试，结算逻辑行覆盖率 100%

## 技术架构

微信小程序原生（WXML/WXSS/JS）+ 微信云开发（免服务器后端）：

```
miniprogram/          小程序前端
├── pages/            页面（房间、计分、玩法配置、帮助等）
├── services/         业务逻辑（scoreService 结算引擎、ruleService 规则引擎）
└── utils/            工具与常量（牌型、赢牌类型枚举）
cloudfunctions/       云函数（Node.js）
├── createRoom        创建房间
├── joinRoom          加入房间
├── settleRound       每局结算
└── ...               新增 getRoomSnapshot 授权分页读取
tests/                自动化测试
├── services/         结算/规则引擎测试（含属性测试）
└── utils/            工具函数测试
docs/                 设计文档、上线 checklist
```

## 规则引擎设计

把规则从硬编码解耦为**规则配置对象 + 查表函数**：房主配置的规则参数存入房间，结算时按该配置算分。不同地区规则细节经多个大模型交叉验证，并梳理牌型间互斥与兼容原则，保证算分正确。

## 测试

```bash
npm test            # 运行全部测试
npm run test:coverage  # 查看覆盖率（scoreService 行覆盖 100%）
```

- **单元测试**：固定输入断言固定输出，覆盖自摸/点炮/杠/流局等场景与边界条件
- **属性测试**（fast-check）：验证「分数守恒」不变式——随机生成 500 组规则与牌局，所有玩家分数变化之和恒为 0

## 运行部署

1. 使用微信开发者工具导入本项目根目录（包含 `project.config.json`）
2. 开通云开发，创建环境并部署 `cloudfunctions/` 下全部云函数
3. 在 `app.js` / 云函数配置中填入你的云开发环境 ID
4. 真机预览测试后提交审核
