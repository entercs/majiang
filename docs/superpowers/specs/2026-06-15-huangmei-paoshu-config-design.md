# 黄梅麻将玩法配置（算炮数可配置化）设计

## 1. 背景与目标

黄梅麻将在不同地区流行时，各牌型对应的"炮数"（fan 值）存在差异。当前的 fan 值写死在 `huangmei.js` 里，无法灵活调整。本功能允许房主在房间内调整各牌型和胡牌方式的炮数，调整后全房间共享同一套配置。

## 2. 方案确认

- **配置权**：房主可修改，所有人都能查看
- **配置后全房间共享同一套 fan 值**，算分时统一使用
- **范围**：仅黄梅麻将，四川麻将暂不支持
- **入口**：`auto-score` 辅助算分页面
- **入口名称**：玩法配置

## 3. 数据模型

在 `rule` 对象中新增两个可选字段：

```js
cardTypeFans: {
  pinghu: 1,      // 默认 1
  qiyidui: 15,    // 默认 15
  pengpenghu: 15, // 默认 15
  qingyise: 15,   // 默认 15
  hunyise: 15,    // 默认 15
  quanqiuren: 30  // 默认 30
}

winTypeFans: {
  dianpao: 0,    // 默认 0
  zimo: 1,       // 默认 1
  caishang: 2,   // 默认 2
  gangshang: 5,  // 默认 5
  qianggang: 5,  // 默认 5
  haidilao: 5    // 默认 5
}
```

- 字段不存在或值为 `null` 时 → 降落到 `huangmei.js` 默认值（向后兼容）
- 新建房间不写入这两个字段，保持干净

## 4. 计番逻辑改造

`huangmei.js` 的 `computeFanBreakdown()` 改为优先从 `rule.cardTypeFans[key]` / `rule.winTypeFans[key]` 取值，无值时降落到默认值。

`auto-score/index.js` 中的 `_recomputeHm()` 同理改造，统一使用查表逻辑。

## 5. 页面改造

### 5.1 页面提示

在 `auto-score` 页面顶部添加一行提示文字：

> 💡 如需调整炮数，请先点击「玩法配置」

### 5.2 入口按钮

在玩法切换栏下方添加「玩法配置」按钮，样式为辅助操作按钮（次要样式）。

### 5.3 配置面板

点击「玩法配置」后弹出底部弹窗，面板内容：

```
┌─────────────────────── 玩法配置 ───────────────────────┐
│                                                        │
│  牌型              炮数                                  │
│  平胡      [-  1  +]  最基本的胡牌方式                    │
│  七对      [- 15  +]  手牌凑齐7个对子                      │
│  碰碰胡    [- 15  +]  全部为刻子（碰牌）的胡牌             │
│  清一色    [- 15  +]  全部为同一花色的胡牌                │
│  混一色    [- 15  +]  同一花色+风牌/箭牌的胡牌             │
│  全求人    [- 30  +]  吃碰杠后只剩单张，且全部吃碰别人的牌  │
│                                                        │
│  胡牌方式        炮数                                    │
│  点炮      [-  0  +]  点炮者单独付分给胡牌者               │
│  自摸      [-  1  +]  自摸胡牌，3家各付分                  │
│  财上开花  [-  2  +]  杠牌补花后自摸                       │
│  杠上开花  [-  5  +]  杠后补牌自摸                        │
│  抢杠      [-  5  +]  他人杠牌时抢胡                      │
│  海底捞月  [-  5  +]  最后一张牌自摸                      │
│                                                        │
│  [取消]                    [应用到房间]（仅房主可用）    │
└────────────────────────────────────────────────────────┘
```

- 房主：「应用到房间」按钮可用；非房主：该按钮灰化并提示"仅房主可修改"
- 面板关闭后，下方番数明细实时反映当前配置值（预览能力）
- 每个配置项的说明文字始终可见（小号灰色字）

## 6. 权限与后端

- 前端在调用 `roomService.updateRule()` 时传入 `cardTypeFans`/`winTypeFans`，后端无需改造
- 房主判断逻辑：复用现有的 `roomStore.isOwner`
